# MIFECO Virtual Consulting — Knowledge Checklist

**Framework Source:** *AI That Works for Small Business* (Bob Mills)
**Purpose:** Track all required data points across the four phases of the engagement. Check off each item as it is acquired.

---

## PHASE 1: INITIAL INTAKE

### Business Profile
- [ ] Business legal name and DBA (if different)
- [ ] Primary industry and sub-industry classification
- [ ] Number of employees (FTE)
- [ ] Annual revenue range
- [ ] Years in operation
- [ ] Current technology stack (all software, tools, platforms used daily/weekly)
- [ ] Current digital presence:
  - [ ] Website status (static / e-commerce / custom / none)
  - [ ] Social media channels actively maintained
  - [ ] E-commerce capability (platform, if applicable)
- [ ] Business locations (single / multiple / remote)
- [ ] Business model (B2B / B2C / Hybrid)

### Pain Points & Time Audit
- [ ] Top 3 most time-consuming weekly tasks (with estimated hours per week)
- [ ] Dread score for each task (1-5)
- [ ] Single biggest operational frustration (verbatim client quote)
- [ ] Customer service:
  - [ ] Volume of inquiries (per day/week)
  - [ ] Channels used (phone, email, chat, social, in-person)
  - [ ] Helpdesk/ticketing system (if any)
  - [ ] Percentage of repetitive/FAQ inquiries
  - [ ] After-hours handling method
- [ ] Sales/marketing process:
  - [ ] Lead generation methods
  - [ ] Lead tracking system (if any)
  - [ ] Typical sales cycle length
  - [ ] Where leads commonly fall through cracks
  - [ ] Current conversion rate (if known)
- [ ] High-value vs. low-value time ratio (estimated %)
- [ ] Time audit raw data (if completed with client)

### Data Readiness
- [ ] Data types collected (check all that apply):
  - [ ] Customer contact information
  - [ ] Purchase history
  - [ ] Support tickets/interactions
  - [ ] Inventory levels
  - [ ] Financial transactions
  - [ ] Website analytics
  - [ ] Employee data
  - [ ] Other: ____________________
- [ ] Data storage method(s):
  - [ ] Spreadsheets (Excel/Google Sheets)
  - [ ] Database
  - [ ] CRM system
  - [ ] Paper/notebooks
  - [ ] POS system
  - [ ] Accounting software
  - [ ] Cloud storage (Google Drive, Dropbox, etc.)
  - [ ] No central system
- [ ] Data quality status:
  - [ ] Known duplicates? (Y/N)
  - [ ] Known outdated entries? (Y/N)
  - [ ] Known incomplete records? (Y/N)
  - [ ] Last date of data cleanup: ___________
  - [ ] Confidence in data accuracy (1-5)
- [ ] Data access/sharing practices:
  - [ ] Defined permissions (Y/N)
  - [ ] Version control in place (Y/N)
- [ ] Existing reports/dashboards (what, how often, who uses)
- [ ] Backup practices
- [ ] Data integration between systems (Y/N — describe)

### Goals & Constraints
- [ ] Primary business goal for 6-12 months (with urgency score 1-5)
- [ ] Secondary goals (list)
- [ ] Budget range for AI investment:
  - [ ] Monthly subscription budget range
  - [ ] One-time implementation budget range
  - [ ] Willing to invest based on ROI case? (Y/N)
- [ ] Technical comfort level — owner (1-5)
- [ ] Technical comfort level — team average (1-5)
- [ ] Timeline urgency and driving event (if any)
- [ ] Concerns/hesitations about AI (verbatim)
- [ ] Past AI experience:
  - [ ] Extensive / Some / Minimal / None
  - [ ] If experienced: tools tried, outcomes, lessons learned

### Risk Awareness
- [ ] Current security practices:
  - [ ] Password manager used (Y/N)
  - [ ] Two-factor authentication (Y/N)
  - [ ] VPN usage (Y/N)
  - [ ] Data protection measures for customer/employee data
  - [ ] Data breach response plan (Y/N)
  - [ ] System update/patch cadence
- [ ] Regulatory/compliance requirements:
  - [ ] GDPR
  - [ ] CCPA/CPRA
  - [ ] HIPAA
  - [ ] PCI-DSS
  - [ ] SOC 2
  - [ ] FINRA/SEC
  - [ ] COPPA
  - [ ] Other: ____________________
  - [ ] None
  - [ ] Current compliance status (certified / in progress / not started / unaware)
- [ ] Privacy practices:
  - [ ] Published privacy policy (Y/N)
  - [ ] Consent collection method
  - [ ] Data deletion/right to be forgotten process (Y/N)
- [ ] Reputational considerations around AI use in their industry
- [ ] Brand sensitivity to automation (high-touch, luxury, healthcare, etc.)

### Stakeholders & Change Readiness
- [ ] Key decision-makers (names, roles, AI stance):
  - [ ] Champion(s): ____________________
  - [ ] Neutral: ____________________
  - [ ] Skeptic(s): ____________________
  - [ ] Final decision-maker: ____________________
- [ ] End users affected by changes (roles, likely reaction)
- [ ] History of change adoption:
  - [ ] Embraced quickly / Gradual / Resistant / Mixed
  - [ ] Reasons for past successes
  - [ ] Reasons for past failures
- [ ] Decision-making style (solo / team discussion / consensus)
- [ ] Change readiness scenario response (saves 10 hrs/wk, 2 weeks adjustment)
- [ ] Employee concerns about job security (Y/N — details)

## PHASE 2: KNOWLEDGE ACQUISITION

### Industry Research
- [ ] Primary industry classification identified
- [ ] 3-5 direct competitors researched
- [ ] Competitor AI adoption profiles created
- [ ] Industry-specific AI benchmarks found
- [ ] Relevant regulations documented
- [ ] Industry-specific AI tools/platforms identified
- [ ] 2-3 similar-business AI case studies found

### Technology Landscape
- [ ] Customer Service AI tools evaluated (2-3 options)
- [ ] Sales & Marketing AI tools evaluated (2-3 options)
- [ ] Operations & Admin AI tools evaluated (2-3 options)
- [ ] Financial AI tools evaluated (2-3 options)
- [ ] Strategy & Analytics AI tools evaluated (2-3 options)
- [ ] AI Agent platform options (if Growth Engine applicable)
- [ ] Each option scored against evaluation criteria (business fit, technical fit, vendor fit)
- [ ] Pricing documented for all shortlisted tools

### Stakeholder Interviews
- [ ] Decision-maker(s) interviewed
- [ ] End users interviewed (at least 2)
- [ ] Skeptics interviewed (if identified)
- [ ] Process owners interviewed
- [ ] Interview notes recorded with key quotes
- [ ] Common themes identified across interviews
- [ ] Concerns and motivations documented per stakeholder

### Web Search Enrichment
- [ ] Competitor AI adoption signals researched
- [ ] Industry AI benchmarks and statistics gathered
- [ ] Tool reviews collected (G2, Capterra, TrustRadius)
- [ ] Tool pricing verified from current sources
- [ ] Recent AI regulation news reviewed
- [ ] Community discussions reviewed (Reddit, LinkedIn, etc.)

### Financial Analysis
- [ ] Direct tool costs calculated (monthly/yearly)
- [ ] Implementation costs estimated
- [ ] Training costs estimated
- [ ] Opportunity cost considered
- [ ] Ongoing maintenance costs estimated
- [ ] Time savings quantified (hours × hourly value)
- [ ] Cost reduction benefits quantified
- [ ] Revenue increase potential estimated
- [ ] Quality improvement benefits noted
- [ ] Employee satisfaction benefits noted
- [ ] Conservative scenario ROI calculated
- [ ] Moderate scenario ROI calculated
- [ ] Optimistic scenario ROI calculated
- [ ] Payback period calculated
- [ ] Total Cost of Ownership (TCO) documented
- [ ] Break-even analysis completed

## PHASE 3: QUALITY ASSESSMENT

### Readiness Scoring
- [ ] Data Readiness: ___ (average of 5 criteria, each 1-5)
- [ ] People Readiness: ___ (average of 5 criteria, each 1-5)
- [ ] Process Readiness: ___ (average of 5 criteria, each 1-5)
- [ ] Technology Readiness: ___ (average of 5 criteria, each 1-5)
- [ ] **Overall Readiness Score:** ___ (average of 4 dimensions)

### Pain Point Prioritization
- [ ] Pain points listed and scored for impact (1-5)
- [ ] Pain points scored for effort (1-5)
- [ ] Impact/Effort matrix plotted
- [ ] Quick wins identified (high impact, low effort)
- [ ] Strategic initiatives identified (high impact, high effort)
- [ ] Fill-ins identified (low impact, low effort)
- [ ] Items to avoid identified (low impact, high effort)

### Opportunity Assessment
- [ ] Each pain point mapped to specific AI opportunity
- [ ] Each opportunity aligned to business objective
- [ ] Data requirements documented per opportunity
- [ ] Estimated impact and effort documented per opportunity

### Risk Assessment
- [ ] Data security risk assessed (likelihood × impact)
- [ ] Privacy risk assessed (likelihood × impact)
- [ ] AI hallucination risk assessed (likelihood × impact)
- [ ] AI bias risk assessed (likelihood × impact)
- [ ] AI drift risk assessed (likelihood × impact)
- [ ] Vendor risk assessed (likelihood × impact)
- [ ] Operational risk assessed (likelihood × impact)
- [ ] Reputational risk assessed (likelihood × impact)
- [ ] Risk mitigation strategies documented for each medium+ risk

### Recommendations
- [ ] Immediate quick wins documented (next 2-4 weeks)
- [ ] Strategic initiatives documented (next 1-3 months)
- [ ] Long-term vision documented (3-12 months)
- [ ] Foundational prerequisites documented (must do first)
- [ ] Not-recommended items documented with rationale

## PHASE 4: DEPLOYMENT PLAN

### Implementation Timeline
- [ ] Days 1-30 (Foundation) weekly plan created
- [ ] Days 31-60 (Implementation) weekly plan created
- [ ] Days 61-90 (Optimization) weekly plan created
- [ ] Milestones and success metrics defined per phase
- [ ] Parallel run duration specified (1-4 weeks)

### Tool Selection
- [ ] Primary tool selected per use case
- [ ] Alternative options documented per use case
- [ ] Pricing confirmed
- [ ] Setup complexity assessed
- [ ] Training requirements estimated
- [ ] Integration requirements documented
- [ ] Risk level assigned per tool

### Change Management
- [ ] Communication plan created (before, during, after)
- [ ] Resistance management strategy documented
- [ ] Implementation team structure defined:
  - [ ] AI Implementation Lead identified
  - [ ] AI Champions Network established
- [ ] Fear of job loss addressed explicitly in plan

### Training Plan
- [ ] Level 1 (Basics) training designed (60 min)
- [ ] Level 2 (Proficient) training designed (90 min)
- [ ] Level 3 (Champion) training designed (120 min)
- [ ] Pre-training materials prepared
- [ ] Post-training support plan created
- [ ] Quick reference guides planned
- [ ] Monthly office hours scheduled

### Success Metrics & KPIs
- [ ] Time savings baseline and target set
- [ ] Cost reduction baseline and target set
- [ ] Revenue impact baseline and target set
- [ ] Quality improvement baseline and target set
- [ ] Customer experience baseline and target set
- [ ] Adoption rate target set (80%+ active users)
- [ ] Employee satisfaction measurement planned

### Risk Mitigation
- [ ] Low adoption contingency planned
- [ ] AI accuracy issues mitigation planned
- [ ] Integration failure contingency planned
- [ ] ROI shortfall response planned
- [ ] Team resistance escalation plan created
- [ ] Vendor issue contingency planned

### Review Cadence
- [ ] Monthly AI review meeting agenda created
- [ ] Quarterly AI strategy review agenda created
