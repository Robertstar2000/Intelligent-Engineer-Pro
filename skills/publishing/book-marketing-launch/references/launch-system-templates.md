# Book Launch System — Template Files

When the user asks to deploy a book launch, create these files:

## book-launch-system/book-info.md

```markdown
# Book Info

**Title:** [Book Title]
**Subtitle:** [Subtitle]
**Author:** [Author Name]
**Amazon Link:** [https://www.amazon.com/dp/...]
**Book Description:**
[2-3 paragraph description]

**Author Bio:**
[2-3 sentence bio]

**3 Key Excerpts:**
1. [Excerpt 1 — 2-3 paragraphs, most compelling]
2. [Excerpt 2 — 2-3 paragraphs, emotional/relatable]
3. [Excerpt 3 — 2-3 paragraphs, thought-provoking]
```

## book-launch-system/book-clubs/outreach-email-templates.md

```markdown
# Outreach Email Templates

## Cold Email to Book Club

Subject: Free discussion guide for [Book Title]

Hi [Name],

I'm reaching out because I think [Book Title] would spark a great conversation at your book club.

[1-2 sentence hook about the book]

I've created a free discussion guide with [N] questions grouped by theme — happy to share it with your group. Here's the Amazon link: [link]

Best,
[Author]

---
## Follow-up Email

Subject: Following up — [Book Title]

Hi [Name],

Just circling back on [Book Title]. If the timing isn't right, no worries — the discussion guide is always available here: [link]

Warmly,
[Author]
```
