# Book Cover Prompt Templates

Reusable prompt templates for AI image generation (Gemini Flash Image / Flux).

## Sci-Fi / Space Opera (2:3 full-bleed)

```
SCI-FI BOOK COVER 6x9 FULL BLEED. Edge-to-edge DRAMATIC epic scene: 
[Setting description filling full width]. 
[Character/focal point with emotional stake]. 
[Backlighting / dramatic lighting description]. 
Colors: [genre palette]. 
Photorealistic, cinematic, high detail. 2:3 aspect ratio.
```

## Sci-Fi / Hard Sci-Fi (3:4 portrait with empty zone)

```
SCIENCE FICTION BOOK COVER. [Scene description]. 
TOP 40% MUST BE COMPLETELY EMPTY — just [sky/void/ceiling] with no details. 
[Lighting and color direction]. 3:4 portrait.
```

## Survival Thriller

```
SURVIVAL THRILLER BOOK COVER. 
[Close-up / high-tension scene]. 
HARSH [light source]. Deep sharp shadows. Gritty, textured. 
High contrast: [palette]. 
TOP 40% EMPTY — just dark sky. 3:4 portrait.
```

## Mystery / Conspiracy

```
MYSTERY THRILLER BOOK COVER. 
[Atmospheric interior scene with tension]. 
Cold [light source] with [accent color] glow. 
Dark figure lurking / shadows. Tense, conspiratorial. 
TOP 40% EMPTY — just ceiling. 3:4 portrait.
```

## When to use full-bleed vs. empty zone

| Use Case | Ratio | Prompt Instruction |
|----------|-------|--------------------|
| Print-ready KDP cover | 2:3 (1200×1800) | Full bleed, edge-to-edge, NO empty zone |
| Digital/eBook cover | 3:4 (1024×1536) | Top 40% empty for title text |
| User says "full width" or "6x9" | 2:3 (1200×1800) | Full bleed, edge-to-edge |
| User doesn't specify | 3:4 (1024×1536) | Top 40% empty initially, can redo as 2:3 if requested |
