# Book Illustration Style Preferences

## Lunar Foundation + Age of Lightships Series

- **Color**: Black, white, and gray only — no color
- **Style**: Pencil sketch
- **Moon**: Realistic cratered moon surface — NO Saturn-like rings
- **Equipment**: Modern — modern rovers, modern rockets, modern space suits
- **Content**: Each chapter image must represent that chapter's title/theme
- **Size**: 600x600 pixels
- **Format**: PNG

## Chapter Title → Image Mapping

Images are named `ch01.png`, `ch02.png`, etc. Each must depict the scene described by that chapter's title. When generating or replacing images, read the chapter titles from the EPUB's nav.xhtml or NCX first, then create a prompt that matches the specific chapter's theme.
