### Fields Explained

- **Canonical Name**: The ONE official name used everywhere. No switching between "Tom/Thomas/Tommy".
- **Aliases/Nicknames**: All other names this character goes by (rank, first name only, pet names). These are allowed in dialogue but the narrative should use canonical name.
- **Role**: Character's function in the story (protagonist, antagonist, mentor, sidekick, etc.)
- **First Appearance**: Chapter number where they first appear
- **Key Relationships**: Who they're connected to and how (spouse, rival, mentor, child, etc.)
- **Voice/Persona Notes**: Speech patterns, personality traits, vocabulary level, emotional baseline, how they react under stress
- **Books Appearing In**: For series characters, list all books they appear in

### Fields Explained

- **Canonical Name**: Locked across ALL books in the series
- **Aliases**: All variants used across books
- **Role**: Consistent role across series
- **Series Debut**: Which book they first appear in
- **Deliberate Changes**: Any intentional changes (e.g., "promoted to Admiral in Book 3", "name change after marriage in Book 2"). If none, write "None".
- **Voice Consistency Notes**: Key phrases, speech patterns, pronouns, emotional baseline that must remain consistent
- **Books**: List of all books in series where character appears

## Naming Rules Checklist (Enforce on Every Review)

- [ ] One canonical name per character — no "Tom/Thomas/Tommy" switching
- [ ] Surnames stable — no mid-book or cross-book changes without in-story explanation
- [ ] No duplicate names for different characters — "Jane Wilson" ≠ 4 different people
- [ ] Pronouns intentional and consistent — they/them must be deliberate and stable
- [ ] Title/rank consistency — pick ONE reference style per scene context
- [ ] Character Map exists (CHARACTER_MAP.md per book, SERIES_CHARACTER_MAP.md per series)
- [ ] Manuscript audited against Character Map — deviations flagged as P0 defects
