# Plot Map Integration for Novel Writing

## When to Create Plot Map

**Mandatory at Phase 0.6** (after Character Map, before Chapter Outline)

The Plot Map is created alongside the Chapter Outline (Step 0.7) — they inform each other.

## Integration with Chapter Outline (Step 0.7)

When generating the 40-chapter outline with 3-5 beats per chapter:

1. **Map beats to Plot Map segments** — each segment (Ch1-5, Ch6-10, etc.) gets 5-10 chapters
2. **Ensure cause→effect in beats** — Beat 3 of Chapter N should cause Beat 1 of Chapter N+1
3. **Escalate stakes per segment** — Segment stakes column must rise
4. **Place twists at segment boundaries** — Key revelations at Ch5, Ch10, Ch15, Ch20, Ch25, Ch30, Ch35, Ch40

## Pre-Writing Verification (Before Each Chapter)

Before writing any chapter:
- [ ] Read Plot Map — verify chapter's segment, conflict, stakes
- [ ] Confirm chapter's twist/revelation advances cause→effect chain
- [ ] Update Plot Map if story takes new direction (note in "Link to Next")

## Post-Completion Audit (After Manuscript)

After completing the book:
1. **Trace 3 main plot threads** from setup through climax to resolution
2. **Verify cause→effect chain unbroken** — no "and then" gaps
3. **Check stakes escalation** — Act I < Act II < Act III < Climax
4. **Verify subplot interweaving** — subplots in ≥2 segments, intersect main plot
5. **Check ending** — surprising AND inevitable
6. **Flag deviations** — any Plot Map deviation = P0 defect

## Common Plot Failures to Avoid (From Iteration 3)

| Failure | Prevention |
|---|---|
| Genre breach | Lock genre in Phase 0.1; Plot Map stakes must match genre |
| Sagging middle | Plot Map stakes column must rise each segment |
| Deus ex machina | Plot Map "Link to Next" must show protagonist agency |
| Dropped threads | Plot Map resolution status tracked per thread |
| Episodic structure | Every "Link to Next" must be specific and causal |
| Duplicate beats | Chapter outline beats must be unique per chapter |
| Undermining climax | Epilogue = hook/extension, not negation |
