## Password Management Guidelines

- Use the company email (or `+alias` variants) for all accounts
- Generate unique passwords per directory (16+ chars, mixed case + digits + symbols)
- Save each to a separate `~/hermes/secrets/{directory}-password.txt`
- **Do NOT** commit credentials files — keep in `~/hermes/secrets/`
- At the end of the session, share all credentials with the user so they can log in independently
