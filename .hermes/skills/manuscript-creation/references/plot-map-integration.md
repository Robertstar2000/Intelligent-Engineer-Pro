# Plot Map Requirements for Manuscript Creation

## Phase 0.6 Extension: Plot Map Creation

After Character Roster (Step 0.6) and before Chapter Titles with Beats (Step 0.7), create the Plot Map.

## Per-Book Plot Map (PLOT_MAP.md)

Create in `{book_dir}/PLOT_MAP.md`:

| Chapter Range | Core Conflict | Stakes | Key Twist/Revelation | Cause→Effect Link to Next | Resolution Status |

## Integration with Phase 0 Steps

### Step 0.4 (Original Plot) → Plot Map
The Original Plot document (Act I-IV structure) maps directly to Plot Map segments:
- Act I (Ch1-10) → Plot Map Ch1-5 + Ch6-10
- Act II (Ch11-20) → Plot Map Ch11-15 + Ch16-20
- Act III (Ch21-30) → Plot Map Ch21-25 + Ch26-30
- Act IV (Ch31-40) → Plot Map Ch31-35 + Ch36-40

### Step 0.5 (Style Spec) → Plot Map
Style Spec's pacing/structure notes inform:
- Stakes escalation rate
- Twist placement
- Cause→effect density

### Step 0.6 (Character Roster) → Plot Map
Character arcs must align with Plot Map segments:
- Each segment's "Core Conflict" must involve protagonist(s)
- "Key Twist" should impact character arc
- "Cause→Effect Link" should reflect character decisions

### Step 0.7 (Chapter Outline) → Plot Map
Each chapter's 3-5 beats must:
- Advance the segment's Core Conflict
- Contribute to the segment's Key Twist/Revelation
- Set up the Cause→Effect Link to Next

## Verification Checklist (Before Phase 1 Writing)

- [ ] Plot Map has 8 segments with all columns filled
- [ ] Stakes escalate: Ch1-5 < Ch6-10 < Ch11-15 < Ch16-20 < Ch21-25 < Ch26-30 > Ch31-35 > Ch36-40
- [ ] Each segment's "Link to Next" is specific and causal (not "and then")
- [ ] 3 main plot threads traceable from Ch1-5 through Ch36-40
- [ ] Subplots appear in ≥2 segments and intersect main plot in Plot Map
- [ ] Series Plot Map shows coherent 4-book arc with hooks
- [ ] No genre breach — stakes/twists match genre benchmarks
