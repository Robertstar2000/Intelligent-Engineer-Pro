# Full Production Pipeline — Lessons from Cindy Lou Series (2025-06-01)

## Pipeline Order (CRITICAL)

1. Write chapters (1 ch per subagent)
2. Spell-check + FIX AI-isms on chapter files
3. Compile manuscripts (chapters -> single .md)
4. Build EPUBs (from compiled .md)
5. Generate covers + marketing infographic
6. Write marketing text files
7. Create KDP packages (ZIP with EPUB + cover + marketing)
8. Copy to USB / backup

Clean BEFORE compiling. Never after.

## Subagent Delegation
- SAFE: 1 chapter per subagent (~3-7 min, 100% success)
- UNSAFE: 5+ chapters (600s timeout guaranteed)
- Sweet spot: 3 concurrent (one per book) = ~3 ch per 5-8 min

## Expanded AI-isms to Flag
leverage->use, tapestry->pattern, furthermore->also, nonetheless->still, subsequently->then, paradigm->model, synergy->cooperation, unlock->expose, seamless->smooth, revolutionary->new, delve->dig, pivotal->key

## KDP Package ZIP Per Book
Kindle/ (EPUB + Cover JPG), Source/ (manuscript.md), Marketing_and_Compliance/ (descriptions, keywords, author bio, AI disclosure, QR codes, infographic), README.md

## User "Do Not Duplicate" Preference
When user says tasks are already in progress: check exact file counts, verify what's missing, report specific status before starting.

## Cover PIL Fallback
Solid gradient + bold sans-serif + 4-layer shadow + geometric decorations. 1024x1536 working -> 1600x2560 KDP JPEG.

## Reader Magnet
3000-5000 words, hooks into existing characters, new case, ends with series hook. Free distribution.
