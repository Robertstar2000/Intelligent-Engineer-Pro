# Character Naming Convention for Bob J Mills' Books

## Restricted Names (DO NOT USE)

These AI-typical or ethnically-diverse names must not appear in any book:
- Elena
- Elena Vasquez
- Chen
- Diego
- Mei-Lin
- Rajiv
- Jean-Luc
- Aisha
- Ana
- Kenji

## Rule

All character first names must come from the top 50 most common US names (SSA data). See `character-name-standardization.md` in this skill directory for the full replacement mapping and standardization technique.
