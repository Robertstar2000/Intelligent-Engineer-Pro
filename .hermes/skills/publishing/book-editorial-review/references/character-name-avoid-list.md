# Character Name Avoid List

These AI-typical / ethnically-diverse names MUST NOT be used as character names in any book. All character first names must come from the top 50 most common US names (SSA data).

## Blocked Names

- Elena
- Elena Vasquez
- Chen
- Diego
- Mei-Lin
- Rajiv
- Jean-Luc
- Aisha
- Ana
- Kenji

## How to Check

During every editorial review, search the manuscript for each name in this list using word-boundary regex (`\bElena\b`, `\bElena Vasquez\b`, etc.). Any match is a P1 defect that must be fixed before the book can pass review.
