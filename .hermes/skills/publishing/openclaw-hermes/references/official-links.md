# Official Publishing and ISBN Links

Use current web search before giving final links because publishing portals and policy URLs can change.

## ISBN

- United States ISBN agency: Bowker.
- Bowker MyIdentifiers: ISBNs, barcodes, and related identifiers.
- For non-US authors, find the official national ISBN agency through the International ISBN Agency directory.

Recommendation: serious wide releases should use publisher-owned ISBNs. Use one ISBN per format.
