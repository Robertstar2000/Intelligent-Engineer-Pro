Search Guide

Use LinkedIn Sales Navigator or standard search with these filters. Target 5–15 new connections per role per day.

HOW TO SEARCH
  1. Open LinkedIn → use the search bar at top
  2. Enter a job title from the list below
  3. Add filter: Location (your target region)
  4. Add filter: Industry (SaaS, Technology, Consulting, etc.)
  5. Sort by 2nd+ connections for warmer outreach
  6. Open each profile → Connect → use note template
