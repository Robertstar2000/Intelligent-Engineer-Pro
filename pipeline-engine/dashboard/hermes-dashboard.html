🔒 About the Native Dashboard

The Hermes Agent native dashboard runs on 127.0.0.1:9119 and is only accessible from this machine. It provides real-time system monitoring, configuration management, API key management, session history, and tool management.

⚡ Quick Launch

To start the Hermes native dashboard from the terminal: hermes dashboard

To access it on this machine: http://127.0.0.1:9119

⚠ Security: The dashboard is bound to localhost only. Do NOT use --insecure as it exposes API keys on the network.
